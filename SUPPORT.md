# Support

## Getting help

- **Documentation:** see the project README and the in-app help.
- **Bugs and feature requests:** open an issue with a minimal reproduction and
  the exact version shown in Settings.
- **Security issues:** follow `SECURITY.md` — do not post exploit details.

## Expectations

This is a small project maintained by a single developer. Issues are triaged in
order of impact; there is no guaranteed response time. Pull requests that
follow `CONTRIBUTING.md` are welcome.
