# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities by opening a private issue or contacting
the maintainers directly. Do not post exploit details in public issues.

## Supported versions

Only the latest published release of Frondose receives security updates.

## Public project scope

The Web project is a static landing page. It contains no credentials, no
runtime secrets, no update server, and no user data. Security-relevant behavior
lives in the Frondose App project; see that project's `SECURITY.md`.
